# 🚑 亚太健康快递 | APEC Health Delivery

> Game Jam 作品 · 主题：APEC × 健康  
> 致敬 APEC 2026 中国主办年  
> **"Building an Asia-Pacific Community to Prosper Together"**

## 🕹 在线试玩

👉 https://wendyyy819.github.io/apec-health-delivery/

## 🎮 玩法

你是亚太地区的紧急医疗调度员。
21 个 APEC 成员经济体的城市中，红色警报亮起就代表有健康危机。
**点击亮起的城市送达医疗物资**，争取在限定时间内拿到最高分！

- ⏱ 30 秒挑战
- ❤️ 生命归零即结束
- 🎯 三档难度可选

## 🌏 设计理念

APEC 由 21 个成员经济体组成，覆盖全球约 60% 人口与近半数贸易量。
健康议题是 APEC 区域合作的重要方向。

本作品用最直观的点击玩法，让玩家在 30 秒内体会
"守护亚太成员经济体健康"的紧迫感与协作精神，
呼应 APEC 2026 主题——共建亚太命运共同体，共促繁荣发展。

纯 HTML + CSS + JavaScript 单文件，零依赖，浏览器直接运行。
